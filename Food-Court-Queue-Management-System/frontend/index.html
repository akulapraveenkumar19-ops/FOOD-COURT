🛠️ Data Structures Implemented in C++

1. Normal Queue (FIFO)

Handles standard waiting customer line. Enqueue at rear, dequeue from front.

2. Circular Queue

Fixed memory buffer with modulo arithmetic for counter display and token cycling.

3. Priority Queue

Serves High (Express/Emergency) orders before Regular and Normal orders.

4. Deque (Double Ended)

Enables VIP fast-track insertion at Front and cancellation removal from Rear.

5. Stack (LIFO)

Maintains recent order history and supports instantaneous Undo Last Order.
