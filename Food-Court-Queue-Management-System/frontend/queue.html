1. Normal Queue (FIFO: First-In-First-Out)

Queue.h / Queue.cpp

Customers wait in order of arrival. Enqueue happens at REAR pointer, Dequeue happens at FRONT pointer.

2. Priority Queue (Multi-Level / Stable Sorted)

PriorityQueue.h / PriorityQueue.cpp

Orders are serviced by priority level: High (Express) ➔ Medium (Regular) ➔ Low (Normal). Within equal priority, FIFO order is strictly preserved.

3. Circular Queue (Token & Counter Buffer)

CircularQueue.h / CircularQueue.cpp

Fixed-size array slots where rear wraps around to 0 using formula rear = (rear + 1) % Capacity to prevent memory fragmentation.

4. Double-Ended Queue (Deque)

Deque.h / Deque.cpp

Supports O(1) insertion and deletion at both FRONT and REAR ends using a Doubly Linked List with prev and next pointers.

5. Order Stack (LIFO: Last-In-First-Out)

Stack.h / Stack.cpp

Maintains recent order history. Clicking Undo Last Order pops the TOP element and reverses the operation.
